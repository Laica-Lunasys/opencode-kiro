# Contributing

This is an independent OpenCode V2 fork of [NachoFLizaur/opencode-kiro](https://github.com/NachoFLizaur/opencode-kiro). File issues or changes against this fork rather than the upstream V1 release.

Use Node.js 20+ and run `npm ci` and `npm run check` before proposing a change. For local integration testing, install and log in with Kiro CLI, then follow the checkout instructions in [README.md](README.md). Tests do not require Kiro credentials; a live request does.
